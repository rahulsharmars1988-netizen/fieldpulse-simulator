# Rahul Sharma - Oil & Gas Management Educational Simulation Package

This package contains a deployable React/Vite app with:

1. FieldPulse OPEX simulator
2. Nodal Analysis simulator
3. Oil & Gas course design package
4. Sanitized LinkedIn posting package

## Local Run

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Upload this folder to GitHub as a new repository.
2. Open Vercel.
3. Click New Project.
4. Import the GitHub repository.
5. Framework preset: Vite.
6. Build command: `npm run build`.
7. Output directory: `dist`.
8. Deploy.
